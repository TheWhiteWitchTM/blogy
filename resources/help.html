Blogy

A black page for a Markdown post. Write in the middle. Preview and Tools stay closed until you open them.

The rows

The top row is words. Each button is as wide as its label: New Post, Open, Save, Publish, Post to Bluesky, Preview, Tools, and Dictate. Preview fills the text area. Tools opens the side pane, and stays lit while that pane is open. The pane has three tabs: Chat, Front matter, and Publish. Publish on the top row is the amber one. Settings is in the File menu. Help is this page, in the Help menu.

The amber arrow at the top of the posts list hides that list. It stays on top of the list. Click it to bring the list back.

Escape, while a post is open, asks you to save, discard the changes, or delete the file. Delete removes that file. Cancel stays in the post. If the word list or Find is open, Escape closes that first.

The row under that formats the post, the same kind of symbols as a word processor. B, I, and the struck ab wrap the selection, or the word you are about to type. Click the same one again to take the marks off.

Heading is the H. It opens the six levels. Pick the same level again and the line becomes a paragraph. Under the levels, the menu lists the headings already in this post. Click one to jump there. Ctrl+1 through Ctrl+6 do the same from the keyboard.

Bullets, Numbers, and Tasks mark the lines you have selected. Enter continues the list. Enter on an empty item ends it.

The code block symbol opens a language list. The post gets a fenced block, the kind that starts with three backticks and the language name, so the published page can color it. Paste the code between the fences. The editor colors keywords, strings, comments, and numbers while you are still here. If the cursor is already inside a block, choosing a language only changes the tag on the opening line.

Image asks for a picture. Publish copies it next to the post. You can also drop a picture on the page. Emoji and Flags search by name. In the text, :smile: and :flag-at: expand when you type the closing colon.

Spelling and Tab

After a couple of letters, a short list opens under the cursor and the rest of the word sits in grey in front of the caret. Press Tab to take the first one. Click any row to take that one instead. Escape puts the list away. Enter still makes a new line.

The list is the same idea as LibreSky. Learned words and names already in the post come first, then the dictionary, shortest match first. A word you have not finished is not marked wrong while it can still grow into a real word.

A lowercase word the dictionary does not know gets a red underline once you leave it. Names and words that start with a capital are left alone. Code, front matter, and web addresses are left alone too. Right-click a wavy word for other spellings, or choose Add to dictionary. Added words are remembered on this machine.

Dictation

Dictate (Ctrl+Shift+D) is a toggle, the last word on the top row. Click it to listen. Click it again to stop. Holding it down does nothing. It writes Markdown, not a flat transcript. It uses the signed-in Grok account, or the xAI key from Settings. While it is on, the microphone audio is sent to xAI and nowhere else. The button stays lit.

Talk in phrases. A pause commits the phrase. The amber text at the caret is what was just heard and has not been committed yet. Say finish the post and Blogy takes the outline already in the editor, plus the site’s tune, and writes the full post. “Write the post” and “complete the post” do the same. A note in the prompt box changes the result. Leave that box empty and the post is written from what is already there.

Inside a code fence, words are written as you say them. New line, punctuation, and end code still work. Say scratch that to take back the last committed phrase.

Find

Ctrl+F opens Find under the post. Enter jumps to the next match. Shift+Enter jumps back. Ctrl+H is Replace. All replaces every match in one step, so one undo brings them back.

The rest of the window

Preview (Ctrl+Shift+V) fills the text area. The editor comes back when you close it. Tools (Ctrl+J) opens the side pane and stays lit while it is open, on any tab. The same key closes it. The tabs are Chat, Front matter, and Publish. Front matter (Ctrl+M) opens the pane on the form. Edits there go straight into the file. The prompt at the bottom of the chat changes what Grok writes. Finish the post reads the draft that is open, uses the site’s tune, and writes the full post into the editor. Leave the prompt empty to finish from what is already there, or type how to change it. A question stays in the chat until you apply it. The prompt fills the width under the chat, and Send is on the row beneath it. Ctrl+Enter sends too.

Save names the file from the title. Publish (Ctrl+Shift+P) saves, commits, and pushes the post in that site’s repo. The Publish tab shows the repo, the branch, and the git command, then runs it. A site can append a signature once. After a publish, Blogy can post the title and the link to Bluesky (Ctrl+Shift+B).

The row under the words is symbols. Hover one for its name.
